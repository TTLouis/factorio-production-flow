Version: 0.1.3
Date: 2026-10-24
  Features:
    - Choose items and fluids in one searchable icon selector, with familiar item categories and a Fluids section.
    - Add item and group favourites to Balance, with Underproducing, OK and Overproducing summary columns.
    - Add Focus Back/Forward navigation, six-material Last visits, a clickable trail and Clear history.
    - Make the chest-stock scan cooldown configurable: minimum 1 game minute, default 5 minutes after each completed scan.
  Changes:
    - Use compact vanilla-style controls, with zoom and labels kept visible and other chart settings in a gear fly-out.
    - Use one fixed Balance heading row aligned with the data, removing the upper category headings.
    - Add space between Empty in and the scrollbar while retaining framed list boundaries and aligned Details.
    - Move Refresh table into the Balance header and remove the footer counters.
    - Keep selector side margins, use the right margin for its scrollbar, and restore chart-settings bottom spacing.
    - Exclude signal-only categories, blueprint parameters and hidden entries from material selection.
    - Remove development tabs, renderer comparison controls, test commands and diagnostic exports from the release.
  Optimizations:
    - Wait for the configured cooldown after each complete chest scan while retaining the 32-entry-per-tick budget.
    - Apply interval changes live without restarting an active scan.
  Bugfixes:
    - Show an empty Focus result for an unrecorded material instead of an unrelated full-factory chart.
    - Preserve the Balance list and scroll position when inspecting a row after live values change.
    - Correct oversized navigation arrows, clipped selector scrollbars and settings fly-out frame spacing.

Version: 0.1.2
Date: 2026-10-24
  Optimizations:
    - Cache GUI children once per Balance table refresh, avoiding repeated full-array copies for every cell.
    - Limit chest sampling to 32 registry visits per tick and keep the previous result until a scan completes.
  Info:
    - Validate exact stock totals on fixed-seed maps with 1,000, 10,000 and 50,000 chests, up to 2.4 million randomized item stacks.
    - Compare local UPS timings with stock sampling enabled/disabled and Balance open/closed, including a working Space Age save.
    - Record average, p95, p99 and maximum update timings; methodology and hardware-specific results are in the repository validation report.
  Features:
    - Count physical stock in ordinary and all logistic chest types, including requester and buffer chests.
    - Include stored items without recent activity as Stock only in Balance.
  Changes:
    - Spread chest reads across ticks and publish only complete stock scans.
    - Clarify that item selection and production measurements do not require logistic storage.
    - Explain stock coverage, sampling and exclusions in help and the mod description.
  Bugfixes:
    - Measure chest contents directly without signed network availability or duplicate reservations.
    - Reset the narrower stock baseline on upgrade to avoid a false trend.
